id: account-recovery
title: 이메일 비밀번호 찾기
description: 이메일 인증 후 로그인 비밀번호 다시 설정하기
---

이메일로 가입한 계정은 이메일 인증을 거쳐 비밀번호를 다시 설정할 수 있어요.

1. 이메일 로그인 화면에서 **비밀번호 찾기**를 선택하세요.
2. 가입한 이메일 주소로 인증번호를 요청하세요.
3. 받은 인증번호를 입력하고 새 비밀번호를 설정하세요.
4. 새 비밀번호로 로그인하세요.

메일이 오지 않으면 이메일 주소와 스팸함을 확인하세요. 소셜 로그인 계정은 이용한 로그인 서비스의 계정 복구 절차를 따라주세요.

로그인 비밀번호와 앱 잠금용 6자리 비밀번호는 서로 달라요. 앱 잠금 복구는 [앱 잠금 안내](./app-lock)를 참고하세요.
