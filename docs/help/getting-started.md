사이사이는 두 사람이 사진·영상과 다이어리를 함께 남기는 공간이에요.

1. 이메일 또는 소셜 계정으로 로그인하세요.
2. 새 커플 공간을 만들거나, 파트너에게 받은 초대 코드를 입력하세요.
3. 공간을 만든 분은 `더보기 > 커플 정보`에서 초대 코드를 확인해 파트너에게 보내세요.
4. 앨범에 사진·영상을 올리거나 다이어리에 하루의 이야기를 남겨보세요.

## 무엇을 할 수 있나요?

- [앨범 만들기](./create-album): 날짜를 정하고 사진과 영상을 함께 보관해요.
- [사진·동영상 공유](./share-album): 추억을 올리고 댓글로 대화해요.
- [다이어리 쓰기](./diary): 글로 기록하고 서로 댓글을 남겨요.
- [다락방 이용하기](./attic): 즐겨찾기 앨범, 메모와 일정을 찾아보세요.

이메일 계정의 비밀번호가 기억나지 않으면 [비밀번호 찾기](./account-recovery)를 이용하세요.
