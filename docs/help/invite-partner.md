## 초대 코드 보내기

1. `더보기 > 커플 정보`를 여세요.
2. 초대 코드 영역에서 코드를 복사해 파트너에게 보내세요.
3. 파트너가 사이사이에 로그인한 뒤 초대 코드를 입력하면 같은 공간으로 연결돼요.

## 연결되지 않을 때

- 공백이나 다른 문구가 섞이지 않았는지, 받은 코드가 맞는지 확인하세요.
- 네트워크 연결을 확인한 뒤 다시 시도하세요.
- 계속 연결되지 않으면 `더보기 > 문의하기`로 상황을 알려주세요.

:::note 커플 해제 전 확인하세요
커플을 해제하면 현재 공간에서 나가게 돼요. 다시 참여하려면 초대 코드가 필요하므로 해제 안내를 먼저 확인하세요.
:::
